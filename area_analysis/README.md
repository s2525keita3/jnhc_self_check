# 地域分析（相模原市 訪問看護）

訪問看護ステーションの**生存曲線**と**人員構成**、営業先（居宅・包括・病院・診療所・相談支援）の**地図とリスト**を、公的オープンデータから作るツールです。

## 使い方

```bash
pip install -r requirements.txt

# 1) 公的データを取得（data/raw/ に保存）
python fetch.py

# 2) 生存曲線には過去の名簿が必要。厚生局名簿のファイルURLを渡すと Internet Archive から過去版を取得
python fetch.py --wayback "https://kouseikyoku.mhlw.go.jp/kantoshinetsu/....xlsx"

# 3) 集計してダッシュボードを出力 → output/dashboard.html をブラウザで開く
python build.py
```

動作確認だけなら、架空のデモデータで試せます：

```bash
python make_demo_data.py && python build.py --data-dir data/demo
```

## データソースと置き場所

自動取得できないときは、配布ページから手動でダウンロードして、下の置き場所に入れてください。
**ファイル名の先頭を `YYYYMM_` にする**と、何月時点のデータかとして扱われます。

| 置き場所 (`data/raw/…`) | 中身 | 使い道 |
|---|---|---|
| `kouseikyoku_houkan/` | 関東信越厚生局「コード内容別医療機関一覧表」の訪問看護（神奈川県）※毎月分 | 生存曲線（開設日・廃止月） |
| `kaigo_opendata/` | 介護サービス情報公表システムのオープンデータ（訪問看護・居宅介護支援・地域包括） | 座標、事業開始日、営業先 |
| `iryou_opendata/` | 医療情報ネット（ナビイ）のオープンデータ（病院・診療所） | 営業先 |
| `shougai_opendata/` | 障害福祉サービス等情報公表システムのオープンデータ（計画相談支援など） | 営業先 |
| `manual/*.csv` | 手作りの一覧（例：市HPの高齢者支援センター一覧）。`category` 列に `houkatsu` などを入れる | 足りない分の補完 |
| `staff.csv` | ステーションごとの人員表（雛形：`templates/staff_template.csv`） | 人員構成 |

列名は `config.py` の `COLS` に候補を並べてあります。表記が違う場合は候補を足してください。
相模原市以外の地域で使うときは、`config.py` の `AREA` を書き換えます。

## 人員表（staff.csv）について

- 事業所ごとに介護サービス情報公表システムの詳細ページから転記します。転記する項目は、常勤・非常勤の人数、常勤換算、経験年数の内訳、前年度の採用者数・退職者数です。
- **年代は公表されていません。** ヒアリングや求人票で分かった分だけ `年代_*` 列に入れてください。空欄のままでも構いません。
- 事業所番号で名簿と突き合わせます。事業所番号が無い行は、名称で突き合わせます。

## 分析の前提と限界

- **開設日**は名簿の指定年月日を使います。**廃止**は、名簿から消えた月の翌月1日とみなします。精度は月単位です。
- **左側切断の補正**：最初の名簿より前に廃止した事業所は、データに現れません。そこで、最初の名簿の時点で既にあった事業所は、その時点の経過年数から観察を始めます（delayed entry）。こうしないと生存率が高く出すぎます。
- **移転・開設者交代**：コードが変わっても、同じ名称で3か月以内に再び名簿に出てきた場合は、同じ事業所が続いているものとして扱います。
- **休止**も名簿から消えるため、廃止として数えられることがあります。
- 人員データは現存する事業所の分しか取れません。そのため、規模別の生存曲線は作っていません。作ると、生き残った事業所だけを見ることになり（生存者バイアス）、結果が歪みます。
- 名簿の本数が12か月分未満だと、廃止の把握が不十分です（build.py が警告を出します）。今後は `fetch.py` を毎月実行して、名簿を貯めていくのが確実です。

## 出力

- `output/dashboard.html`：生存曲線（全体／開設年代／法人種別／区）、区別の事業所数、人員構成、地図、営業先リスト
- `output/station_history.csv`：ステーションごとの開設〜廃止の履歴
- `output/sales_targets.csv`：営業先の一覧。`config.py` の `OWN_STATION` を設定すると、自ステーションからの距離順に並びます
- `output/facilities.csv`：対象地域の全施設
