# 介護事業所情報取得ツール（居宅介護支援 / 訪問看護）

厚生労働省「介護サービス情報公表システム」から事業所情報を取得し、Excelに出力します。
旧 `itakukaigokensaku` の後継として、**市区町村をまとめて指定できる**ようにしたものです。

## 旧ツールからの変更点

| | 旧ツール | 本ツール |
|---|---|---|
| 市区町村の指定 | 1つずつ選択して実行 | **複数まとめて指定**（`神戸市*` で全区、`ALL` で県内全域） |
| サービス種別 | 居宅介護支援のみ | **居宅介護支援＋訪問看護**（設定で追加可） |
| 出力 | 1市区町村＝1シート | **統合シート（全件）＋市区町村別シート**の両方（C案） |
| 中断時 | 最初からやり直し | **続きから再開**（`logs/progress.json`） |
| 項目定義 | parameters.csv | `config/fields_*.csv`（見出し語ベースで構造変更に強い） |
| 体裁 | 素のまま | オートフィルタ・枠固定・罫線、日付と営業時間を整形 |

## 使い方（かんたん版）

1. `ツールを実行.bat` を **ダブルクリック**
2. 必要な部品の準備が自動で走ります（初回のみ数分）
3. そのまま取得が始まります

Python が入っていない場合は、`ツールを実行.bat` が配布サイトを開いて案内します。
インストール時に **「Add python.exe to PATH」に必ずチェック**を入れてください。

設定を変えるときは `設定を開く.bat` をダブルクリックするとメモ帳で開きます。

Google Chrome がインストールされていれば、ドライバは自動で用意されます。

## 使い方（コマンドから）

```
pip install -r requirements.txt
python main.py
```

### 2. 設定

`settings.ini` を編集します。

```ini
[search]
pref = 兵庫県
cities = 神戸市*, 西宮市, 尼崎市, 芦屋市
services = 居宅介護支援, 訪問看護
```

`cities` の書き方:

| 書き方 | 意味 |
|---|---|
| `西宮市, 尼崎市` | カンマ区切りで複数指定 |
| `神戸市*` | 前方一致。神戸市の全9区をまとめて取得 |
| `ALL` | 都道府県内の全市区町村 |
| `@cities.txt` | テキストファイルで指定（1行1自治体） |

### 3. 実行

```
python main.py
```

`.exe` の場合はダブルクリック。`settings.ini` の `pref` / `cities` が空なら対話で聞きます。

```
python main.py --pref 兵庫県 --cities "神戸市*" --services "訪問看護"
python main.py --list-cities        対象都道府県の市区町村名を一覧表示
python main.py --restart            前回の進捗を捨てて最初から取得
```

実行中に出力先のExcelを開いていると保存できないため、閉じておいてください
（開いていた場合は `_1.xlsx` として保存します）。

## 出力

`介護事業所一覧_YYYYMMDD.xlsx`

- `居宅_全件` / `訪看_全件` … サービスごとの統合シート（先頭に「市区町村」列）
- `居宅_西宮市` `訪看_神戸市中央区` … 市区町村別シート
- `実行サマリ` … 取得条件・件数・失敗した検索・要確認の列

ヘッダーは旧ツールと同じ3段構成（1行目:大見出し／2行目:中見出し／3行目:項目名、4行目からデータ）です。

## フォルダ構成

```
/
├ ツールを実行.bat            … これをダブルクリックすると実行されます
├ 設定を開く.bat              … settings.ini をメモ帳で開きます
├ main.py                    … 本体（.bat から呼ばれます）
├ settings.ini               … 設定ファイル
├ config/
│  ├ prefectures.csv         … 都道府県コード
│  ├ services.csv            … 取得するサービス種別の定義
│  ├ fields_kyotaku.csv      … 居宅介護支援の項目定義
│  └ fields_houkan.csv       … 訪問看護の項目定義
├ src/                       … 本体
├ tests/                     … テスト（ネットワーク不要）
└ logs/
   ├ itakukaigokensaku.log   … 実行ログ
   ├ progress.json           … 再開用の進捗
   └ html/                   … dump_html = True のときのHTML保存先
```

## サイトの構成が変わったとき

このツールは **画面に表示されている見出し語** で値を探します
（`id` や `class` に依存しないので、デザイン変更では壊れません）。

見出し語そのものが変わった場合は、`config/fields_*.csv` の `lookup` 列に
候補を `|` 区切りで足すだけで対応できます。コードの修正は不要です。

```csv
column,lookup,transform,group1,group2
所在地,kv:所在地|kv:事業所の所在地|kv:事業所所在地,addr,,
```

`lookup` の書き方:

| 記法 | 意味 |
|---|---|
| `kv:所在地` | 「所在地」という見出しの隣のセルの値 |
| `matrix:看護師/常勤` | 行見出し「看護師」×列見出し「常勤」のセルの値（行・列は逆でも可） |
| `ctx:city` | 検索条件など、ツール側が持っている値 |

`transform` は `text` / `int` / `date` / `time` / `addr` / `yesno` / `space` / `trim`。

うまく取れない列があるときは `settings.ini` で `dump_html = True` にして実行すると、
`logs/html/` に実際のHTMLが保存されます。

## 項目が全部空になる場合

実行後に「※ ほぼ全件が空欄の列があります」と表示されたら、その列の見出し語が
変わっています。`logs/html/` のHTMLを見て `lookup` を直してください。

## テスト

```
python -m unittest discover -s tests -v
```

ネットワークに接続せず、抽出ロジックとExcel出力を検証します。

## .exe を作る

```
pip install pyinstaller
build.bat
```

`dist/itakukaigokensaku.exe` が出来ます。`settings.ini` と `config` フォルダを
同じ場所に置いてください。

## 注意

- サイトへの負荷を避けるため、ページ遷移ごとに `settings.ini` の `wait`（既定1秒）だけ待機します。短くしすぎないでください。
- セキュリティソフトで `.exe` がブロックされる場合は、作業フォルダを監視対象外に設定してください。
