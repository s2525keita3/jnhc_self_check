# 研修テーマ候補・年間計画（2年分の記録作成用）

> 関谷様にピックアップしてもらうための候補一覧。月1回のルールブック（「CCS」）読み合わせ・事例共有を研修実績として活用する。
> 法定で必要な研修の範囲は、指定基準・介護サービス情報公表システムの記載をコンサル側で確認して追記予定。

## 1. 位置づけ
- 法定（運営基準上求められるもの）＋ 自社で定めた継続研修（年◯回）を、毎年同じ枠組みで実施・記録すれば足りる。
- 毎年同じテーマでOK。

## 2. 法定・運営基準関連で押さえたいテーマ（要確認）
| テーマ | 備考 |
|---|---|
| 虐待防止 | 委員会議事録と連動（2年分作成中） |
| 感染症の予防・まん延防止 | 委員会・訓練と連動 |
| 業務継続計画（BCP）・災害対応 | ハザードマップ運用と連動させると効率的 |
| 身体拘束等の適正化 | 要否を確認 |
| 個人情報保護 | 今回の契約書改定・ICT連携と連動 |
| ハラスメント防止 | 要否を確認 |

## 3. 自社の継続研修（既存の取り組みから）
| テーマ | 素材 |
|---|---|
| 接遇 | 月1回の事例共有（「こういう対応だと誤解される→こうする」） |
| 社内ルールブック読み合わせ | 毎月の「CCS」読み合わせ（毎月範囲が違う） |
| 褥瘡の処置 | 実際の利用者ケースを題材に |
| フットケア | スタッフの関心テーマ |
| ICT情報連携と記録の書き方 | 本日の説明資料をそのまま教材に |

## 4. 記録の残し方（1回分の様式）
```
研修名：
日時：　　　　　場所／形式：
講師：　　　　　参加者：
目的：
内容（要点）：
参加者の意見・気づき：
今後の業務への反映：
資料：（添付）
```

## 5. 決めてほしいこと
- 年間の回数（例：法定◯回＋月1回の読み合わせ）
- 上記候補から採用するテーマ（自社継続研修として2つ程度）
