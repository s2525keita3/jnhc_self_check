# 用語集

本システムやコンサル内で使う用語・略語を統一するための辞書。
新しい用語が出たら追記する（表記揺れ防止＝検索性・商品化の品質に直結）。

| 用語 | 意味 | 備考 |
|---|---|---|
| ナレッジベース | 全セッション横断で再利用する知見の蓄積 | 個社情報は含めない（匿名化済み） |
| PDCA | 施策の仮説検証サイクル | 1施策1ファイルで `03_PDCA/` に蓄積 |
| 受け皿 | 集客した見込み客を成約に変える仕組み（初回面談など） | 入口より先に整える |
| ひと言キャッチ | 顧客が他人に説明しやすい短い自己紹介文 | 紹介発生率を上げる（KH-001） |
| 転用候補 | ナレッジを二次活用する行き先 | SNS / 協会 / 起業塾 / 商品 等 |
| MCS | メディカルケアステーション。医療介護連携用のクラウド型情報共有ツール | ICT情報連携加算の要件を満たすツール（MN-001） |
| 返戻 | 請求内容の不備等でレセプトが差し戻されること | 入金が遅れる。新加算は少人数で試行（KH-002） |
| 厚生局 | 地方厚生（支）局。医療保険の届出先・照会先 | 書き起こしで「法制局」と誤変換されやすい |
| 90日ルール | ICT情報連携加算で活用する情報は90日以内に記録されたものに限る | MN-001 |
